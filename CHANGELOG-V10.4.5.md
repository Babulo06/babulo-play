# BaBuLo Play V10.4.5

- Removida a descrição extra da gestão de contas.
- Gestão de Artistas, Ouvintes e Admins continua separada por abas.
- Owner pode apagar permanentemente contas ADMIN, com proteção contra apagar OWNER/própria conta.
- ADMIN entra numa área pessoal própria, sem o dashboard financeiro/Owner.
- Perfil do ADMIN mostra nome completo, telefone, data de nascimento/idade, email, estado, cargo e permissões.
- ADMIN pode atualizar os próprios dados pessoais.
- As permissões atribuídas pelo Owner são apresentadas como os únicos acessos autorizados.
- Criação de ADMIN aceita nome completo, telefone e data de nascimento.
- Migração 018 adicionada para o perfil pessoal dos ADMIN.
