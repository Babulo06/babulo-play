# BaBuLo Play V10.4.25

## Perfis nas plataformas — identificação automática
- Removida a interface de links/IDs plataforma por plataforma do artista.
- Adicionado botão único de identificação automática.
- A API usa integrações oficiais disponíveis; Spotify é pesquisado automaticamente quando configurado.
- Integração opcional `ARTIST_DISCOVERY_URL` / `ARTIST_DISCOVERY_TOKEN` permite um parceiro autorizado devolver perfis de várias plataformas.
- Resultados automáticos ficam pendentes de confirmação quando necessário.
- TikTok, Instagram, Facebook e YouTube continuam como destinos de conteúdo, não como perfis musicais criados pela BaBuLo.
- Perfil central do artista continua separado e alterações entram na fila de sincronização para serviços que suportarem atualização oficial.
