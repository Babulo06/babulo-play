# BaBuLo Play V10.4.3

## Gestão de contas reorganizada
- Abas separadas para Artistas, Ouvintes e Admins.
- Cada aba carrega apenas o respetivo tipo de conta.
- Perfil completo ao clicar numa conta.
- Ações de Ativar, Suspender/Desativar e Bloquear ficam dentro do perfil.
- Perfis de artistas mostram dados profissionais, verificação, lançamentos, levantamentos, streams, sessões e auditoria.
- Perfis de ouvintes mostram contacto, verificações, streams, sessões e auditoria.
- Perfis de Admin mostram cargo/função e permissões.

## Funções dos ADMIN
O OWNER pode criar um ADMIN definindo: cargo/função e permissões individuais para Ouvintes/contas, Artistas, Admins/equipa, Lançamentos, Finanças, Levantamentos, Moderação, Analytics e Configurações.

## Segurança
- Permissões dos ADMIN são guardadas na base de dados.
- A API valida permissões no backend; esconder botões no frontend não é a única proteção.
- OWNER mantém controlo total e proteção da própria conta.
