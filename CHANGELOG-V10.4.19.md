# BaBuLo Play V10.4.19 — Spotify Artist Mapping

- Pesquisa de artistas no Spotify através da Web API com Client Credentials.
- Seleção do perfil oficial e preenchimento automático de Artist ID + URL.
- Validação de um Spotify Artist ID no backend.
- Variáveis privadas: SPOTIFY_CLIENT_ID e SPOTIFY_CLIENT_SECRET.
- Esta integração é para Artist Mapping/pesquisa; não representa entrega direta de música ao Spotify. A distribuição musical real depende de um parceiro/conector de ingestão autorizado.
