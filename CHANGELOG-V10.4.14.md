# BaBuLo Play V10.4.14

- Publicidade passa a ser operada pelo ADMIN com permissão ADS.
- ADMIN cria/edita campanhas, criativos, preços e escolhe os espaços de exibição.
- ADMIN regista o pagamento e envia a campanha para aprovação do Owner.
- Owner apenas aprova/rejeita e monitoriza; aprovação coloca a campanha ACTIVE automaticamente.
- Rejeição devolve a campanha ao ADMIN para correção.
- Criada relação campanha → múltiplos espaços publicitários.
- A entrega de anúncios continua usando a mesma API para Web, Android e iPhone.
